PBill делит общие расходы между друзьями, в семье или с соседями по квартире: в отпуске, в общей квартире или на вечеринке. Его особенность: у каждого участника есть <b>вес</b>, поэтому один плательщик может представлять целую семью.

<ul>
<li>Один человек считается за 1, пара за 2, пара с ребёнком за 2,5 или 3…</li>
<li>Тот, кто участвует, но не платит (гость, ребёнок), может иметь вес 0.</li>
</ul>

PBill намеренно прост: без аккаунта, без облака, без рекламы, без статистики и графиков, только расходы и кто кому сколько должен. При этом он охватывает все способы делить затраты: неравные доли, участники, присоединившиеся позже, кто-то, кто оплачивает только часть расходов, возвраты денег между участниками.

<b>Возможности</b>

<ul>
<li><b>Счета</b>: отдельный счёт для каждого общего бюджета (поездка, квартира…), у каждого своя валюта.</li>
<li><b>Участники</b> с весом по умолчанию и периодом участия (дата начала и необязательная дата окончания): новые расходы по умолчанию делятся между участниками, присутствующими на их дату.</li>
<li><b>Расходы</b> делятся пропорционально весам. Для отдельного расхода можно изменить веса или исключить участников, сразу видя долю каждого.</li>
<li><b>Категории</b>: необязательная категория для каждого расхода (продукты, ресторан, проживание, автомобиль, поездки…), показанная значком.</li>
<li><b>Точные суммы</b>: каждое разделение в точности даёт сумму расхода, до копейки.</li>
<li><b>Балансы</b> всех участников и <b>предлагаемые возвраты</b>, отмечаемые как оплаченные одним касанием; ручные возвраты между участниками.</li>
<li><b>PDF-отчёт</b> об уплаченных, причитающихся и возвращённых суммах, оставшихся возвратах и всех расходах, для просмотра или отправки.</li>
<li><b>Языки</b>: английский, французский, немецкий, испанский, итальянский, русский и вьетнамский.</li>
</ul>

<b>Конфиденциальность</b>

Без аккаунта, без доступа к сети, без отслеживания, без разрешений: данные остаются на устройстве и покидают его, только когда вы сами отправляете PDF-отчёт.
